# Aner

Aner is being developed as an open-source programming language and ecosystem for data science, scientific computing, and AI, with simplicity, performance, and understanding at its core.

**Development preview:** A public language source release is planned. The software license and contribution process are not finalized. No native runtime or VS Code extension is available as a public download.

## Direction and founding principles

> Aner should make it easier not only to compute an answer, but to understand where it came from, evaluate whether it deserves confidence, and take responsibility for how it is used.

The [proposed founding charter](https://anerlang.org/principles) sets out our vision, mission, and ten principles: AI-native, human-led; clarity; transparency; traceability; reproducibility; ethics; privacy and security; resource responsibility; openness and interoperability; and fair community stewardship. These commitments describe direction, not proof of implemented capabilities or safeguards.
